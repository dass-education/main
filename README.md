# DASS メインサイト

通信制高校のサポート校から始まったDASSと、4つの教育事業をまとめる公式メインサイトです。

## 公開用ファイル

- `index.html`
- `style.css`
- `script.js`
- `assets/`

上記を同じ階層のままWebサーバーへアップロードすると動作します。フォームやデータベースは使用していません。

## 掲載順

1. DASSカレッジ
2. DASSハイスクール
3. DASS語学留学
4. DASSキャリアデザイン

## 確認

```bash
npm run build
```

公開用ファイルは `dist/` に生成されます。
